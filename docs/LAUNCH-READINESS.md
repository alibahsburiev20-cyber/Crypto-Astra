# Готовность к запуску

Документ отвечает на один вопрос: **что уже работает, а что нет**. Здесь нет
прогнозов доходности и обещаний цены ASTRA — только факты о коде и о том, что
ещё нужно сделать руками.

Обновлён: 2026-11-17.

## 1. Что работает в проде

| Блок | Состояние | Проверка |
| --- | --- | --- |
| Регистрация, вход, сессии | Работает | `POST /auth/register`, `/auth/login`, `/auth/refresh` |
| Мир: корабли, рейсы, топливо, ремонт, крафт | Работает | `/me`, `/expeditions/*`, `/craft/*` |
| Рынок ресурсов | Работает | `/market/*`, налог и эскроу в журнале |
| Сезон, миссии, Pass, гильдии, рефералы | Работает | `/season`, `/missions`, `/pass/*`, `/guild/*` |
| Арена (мини-игра) | Работает | `/minigame`, `/minigame/start`, `/minigame/finish` |
| Спрайты | 100 % PNG | тест `sprites.test.ts`, 0 SVG в `client/` |
| Astra Pay: витрина, счета, зачисления | Включено на mainnet | `/pay/status.json` → `payments: true` |

Проверенный ответ прод-статуса (`/pay/status.json`):

```json
{ "payments": true, "deposits": true, "purchases": true,
  "network": "mainnet", "wallets": "signer_required",
  "payouts": false, "sweep": false, "schema": "ready" }
```

## 2. Что появилось в этом релизе

- **Гараж.** Три ячейки на старте, потолок восемь, ячейка стоит 200 ASTRA,
  Premium добавляет одну. Корабль нельзя купить в полный гараж — верфь отдаёт
  `garage_full` до списания ASTRA.
- **Модули по кораблям.** Экран «Модули» показывает конкретный корабль: его
  слоты, его установленные модули и его эффекты. Раньше все корабли были в
  одной простыне.
- **Косметика видна другим.** След двигателя рисуется в арене, цвет позывного
  применяется в топбаре, рамка профиля — на карточке пилота.
- **Premium.** Значок, эксклюзивный корпус, +1 ячейка гаража, +2 попытки
  арены. Никаких процентных бонусов к доходу или рейтингу. Авто-клейм и
  приоритет в гильдии пока **не** сделаны — см. `docs/BACKLOG.md`.
- **Арена.** Лидерборд по победам (затем по лучшему счёту), недельная цель:
  20 побед за календарную неделю (с понедельника UTC) → 150 ASTRA разово.
- **Админка мира.** `/admin/world` (сводка и сверка журнала),
  `/admin/world/freeze`, `/admin/world/grant` с обязательной причиной и записью
  в `admin_log`. Страница — `/admin`, закрыта `noindex`, вход по почте и токену
  (настройка — `docs/ADMIN.md`).

## 3. Что заблокировано и почему
| Блокер | Что нужно | Кто может | Когда снимается |
| --- | --- | --- | --- |
| Покупки USDT | Worker `astra-pay-signer`, 3 секрета, `[[services]]` | владелец Cloudflare-аккаунта, см. `docs/PAY-SIGNER.md` | бесплатно, ~30 минут |
| Проверка покупки | одна тестовая покупка на 1 USDT + TRX на комиссию | владелец кошелька | **единственные реальные деньги** (~2 $), можно отложить |
| Выплаты и sweep | отдельное решение + флаг | сознательно выключено | не нужно для запуска |
| Домен | **не блокер**: работаем на бесплатном `*.workers.dev` | не требуется | не нужен |
| Юридическая часть | оператор в Таджикистане; правила криптовалют и налогов зависят от местного закона и от страны игроков | владелец проекта + местный юрист | до первых посторонних платежей |

Выполняет эти шаги один раз либо владелец, либо внешний агент с доступом к
Cloudflare: пошаговое задание — `docs/CLOUDFLARE-AGENT-TASK.md`, готовый промпт
для вставки в чат исполнителю — `docs/CLOUDFLARE-AGENT-PROMPT.md`. Технические
шаги (секреты, Signer, админка, нагрузка, бэкапы) денег не стоят.

Пока Signer не настроен, витрина показывает «Нужен кошелёк» и покупка не
проходит. Это ожидаемое поведение, а не сбой.

## 4. Честный экран пула

Пул общий для сезона: доля участия считается **по внесённым Astra Coin, а не по
очкам**. Экран пула показывает только суммы, которые реально лежат в пуле, и
явно пишет, что выплат нет, пока не включён флаг. Никаких «ожидаемых
доходностей» в интерфейсе нет и не должно появляться.

## 4.1. Чего мы не продаём

- Товар «Свой позывной» отключён: серверного ника нет, значит и продавать
  нечего.
- Косметика сейчас видна только владельцу: рамка и след рисуются на своём
  экране. Показ другим игрокам — в `docs/BACKLOG.md`, пункты A1–A2.

Полный список оставшегося — `docs/BACKLOG.md`.

## 5. Перед публичным анонсом

1. Настроить Signer и провести тестовую покупку 1 USDT.
2. Включить Turnstile-ключи в проде (`/config` отдаёт site key).
3. Проверить `docs/API.md` на соответствие фактическим ответам.
4. Прогнать `npm run check` на чистом клоне (typecheck + unit + e2e).
5. Подтвердить, что в `client/` нет SVG и все картинки — PNG.
6. Решить по юридической части. Домен — опционально и только за деньги владельца.

## 6. Известные ограничения

- Топливо восстанавливается до потолка; оффлайн-начисление ограничено, чтобы
  нельзя было «накликать» экономику за неделю отсутствия.
- Арена считает трассу на сервере: клиент присылает только позицию по времени,
  сервер пересчитывает результат.
- Журнал (`ledger`) — источник истины. Если сверка не сходится, мир можно
  заморозить из админки; заморозка блокирует действия игроков, чтение остаётся.
- Пул, выплаты и sweep выключены по умолчанию. Включение — отдельное решение
  владельца, а не техническая кнопка.
