# AWS: что это, сколько стоит и нужно ли нам

Проверено 18.11.2026 по документации AWS и страницам тарифов.

## 1. Что такое AWS

Amazon Web Services — это аренда компьютеров, баз данных и хранилищ, которыми
управляешь через API и консоль. Не «один сервер», а набор сервисов:

| Что нужно | Сервис AWS |
|---|---|
| Запустить наш код | Lambda (функции) или ECS/App Runner (постоянный процесс) |
| База данных | RDS PostgreSQL / Aurora или DynamoDB |
| Файлы и архивы | S3 |
| Письма | SES |
| Домен, DNS, сертификаты | Route 53, ACM |
| Кэш и очереди | ElastiCache, SQS |
| Модели ИИ по API | Bedrock |

Платишь за фактическое использование: часы работы, гигабайты, миллионы запросов.
Минус — счёт непредсказуем, если не поставить лимиты.

## 2. Про «$200 без карты» — почти правда

С 15 июля 2025 у AWS новая бесплатная программа вместо старых «12 месяцев»:

| Что | Как есть |
|---|---|
| Кредит при регистрации | **$100** сразу |
| Дополнительно | до **$100** за пять заданий по $20 (инстанс EC2, модель в Bedrock, бюджет, Lambda-приложение, база RDS) |
| Итого | до **$200**, но второй $100 надо заработать |
| Срок | **6 месяцев** или до исчерпания кредита — что раньше |
| Что потом | бесплатный план **закрывается**; данные хранятся 90 дней, чтобы успеть перейти на платный |
| Карта | с 16 сентября 2026 **большинству новых клиентов карта не нужна** — регистрация по почте или соцаккаунту |

Подвох, о котором не пишут в рекламе: **выполнение заданий тратит те же
кредиты**. Например, чтобы получить $20 за базу RDS, ты эту базу запускаешь и
платишь из кредита. То есть «$200» — это не $200 на всё, а потолок, внутри
которого часть уходит на сами задания.

И главное: **через 6 месяцев кредиты кончаются, а вместе с ними и бесплатный
план**. Дальше — обычные тарифы AWS, которые для нашей игры дороже Cloudflare.

## 3. «Продают ли они API»

Тут два разных смысла, и оба важны.

- **API как способ управлять инфраструктурой** — да, но это не товар: ты платишь
  за ресурсы, а API бесплатный.
- **API как доступ к моделям ИИ** — да, это реальный товар: **Amazon Bedrock**
  продаёт вызовы моделей (Claude, Llama и другие) по цене за токены. Если ты
  имел в виду «можно ли у AWS купить ИИ по API» — можно, и это одна из пяти
  активностей, за которые дают кредиты.

## 4. Сколько будет стоить нам

Прикидка для нашей игры (одна игра, до 1 000 игроков в день, база небольшая):

| Вариант | Что входит | В месяц |
|---|---|---|
| **Cloudflare Free** (сейчас) | Workers, D1, DO, R2 | **$0** |
| **Cloudflare Paid** | то же + лимиты ×100 | **$5** (+НДС) |
| AWS, минимум | Lambda + DynamoDB + S3 + SES | **$5–20** |
| AWS, «как принято» | Lambda + RDS PostgreSQL (db.t4g.micro) + S3 + SES | **$25–40** |
| AWS, Aurora Serverless v2 | минимум 0.5 ACU даже в простое | **от ~$45** + запросы |

Плюс к AWS: домен и хостинг статики, CloudFront, логи CloudWatch (они платные и
незаметно дорогие), резервные копии, NAT-шлюз, если понадобится VPC.

**Вывод по деньгам:** на нашем масштабе AWS дороже Cloudflare в 5–10 раз и
требует постоянной работы: лимиты, IAM, обновления, мониторинг.

## 5. Можно ли к ним перейти технически

Да, но это переписывание, а не переезд. Сопоставление:

| У нас | В AWS | Сложность |
|---|---|---|
| Worker (роуты) | Lambda + API Gateway или App Runner | 2–3 дня |
| Durable Object мира (по одному запросу за раз) | **прямого аналога нет**: DynamoDB с условными записями или Postgres с блокировками | **1–2 недели**, самое дорогое |
| WorldLobby (места) | та же транзакция в Postgres/DynamoDB | 1–2 дня |
| alarm() и jobs | EventBridge + SQS | 2–3 дня |
| D1 | RDS Postgres или DynamoDB | 3–5 дней |
| R2 | S3 | 1 день |
| Turnstile | **работает как есть** — внешний API | 0 |
| Cloudflare Email | SES | 1 день |
| Админка, бэкапы, алерты | заново на IAM/CloudWatch | 2–3 дня |

Итого **3–6 недель** и постоянная операционная нагрузка. Turnstile переезжает
без изменений, потому что это обычный внешний API.

## 6. Как платить, если карты нет

AWS не принимает крипту, но у него есть варианты, которых нет у Cloudflare:

- **SEPA-прямое списание** — работает в 10 странах, включая **Германию**. Нужен
  банковский счёт, карта не нужна. Это единственный путь «без карты» у больших
  облаков.
- **Advance Pay (банковский перевод)** — предоплата переводом, для Европы.
- **Виртуальная карта, пополненная криптой** — как и с Cloudflare, работает
  через раз: AWS проводит проверочное списание и сверяет биллинг-страну.

То есть если у тебя есть немецкий банковский счёт, но нет Visa/Mastercard,
**AWS окажется доступнее Cloudflare**. Но это единственное его преимущество в
нашей ситуации.

## 7. Вердикт

1. **Переезжать на AWS сейчас — нет.** $200 кредитов закончатся через полгода,
   вместе с ними закончится и бесплатный план, а счёт вырастет в 5–10 раз.
2. **Кредиты стоит использовать как песочницу**, если хочется потрогать Lambda,
   Bedrock или RDS. Для самой игры они ничего не решают.
3. **Bedrock — единственная причина смотреть в сторону AWS всерьёз**, и только
   если понадобится ИИ в игре (генерация описаний планет, помощник новичку).
   Это можно подключить и с Cloudflare: Bedrock доступен по API из любой среды.
4. **Cloudflare остаётся нашей платформой**: она дешевле, не требует
   администрирования и не закрывается через 6 месяцев.
