# Спрайты: только PNG

Правило проекта, без исключений: **всё, что видит игрок, — PNG.** Иконки кнопок,
навигация, вход и выход, фон страницы, фон арены, корабль, астероиды, кристаллы,
взрыв. SVG в `client/` нет вообще, и тест `worker/test/unit/sprites.test.ts`
следит, чтобы он не вернулся.

## Почему так

- **Кеш и загрузка.** PNG отдаётся статикой с ETag и живёт в кеше браузера
  предсказуемо; SVG с инлайновыми стилями каждый раз проходит парсер.
- **CSP.** У нас `style-src 'self'`: инлайновые стили в SVG ломаются, а PNG — нет.
- **Один формат на всё.** Дизайнеру не нужно помнить, где SVG, а где растр.

## Как собрать

```bash
bash scripts/build-sprites.sh
```

ImageMagick рисует фигуры по координатам, поэтому спрайты воспроизводимы: нет
«магических» картинок, которые нельзя пересобрать.

| Что | Куда | Размер |
| --- | --- | --- |
| Иконки кнопок (вход, регистрация, выход, играть, забрать, купить, обновить, трофей, звук) | `client/icons/ui/*.png` | 48×48 |
| Иконки навигации, которых не было раньше (бонусы, магазин) | `client/icons/nav/*.png` | 40×40 |
| Корабль, кристалл, астероиды ×3, взрыв | `client/sprites/arena/*.png` | 128–200 px |
| Фоны: космос, арена, hero | `client/sprites/bg/*.png` | 1000–1920 px |

## Правила для новых картинок

1. Не больше **400 КБ** на файл (тест проверяет): мобильный интернет не резиновый.
2. Прозрачный фон у спрайтов, непрозрачный у фонов.
3. Имя — латиницей, в нижнем регистре, через `_`.
4. Ссылки в разметке — абсолютные от корня (`/sprites/...`), иначе превью-сборка
   и прод разойдутся.
5. Новый спрайт добавляется в `scripts/build-sprites.sh` и в тест — иначе он
   потеряется при следующей пересборке.
