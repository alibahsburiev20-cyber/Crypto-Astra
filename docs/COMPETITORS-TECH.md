# Инфраструктура конкурентов: что видно снаружи

Дата проверки: 18.11.2026. Метод: публичные страницы самих проектов, отпечатки
технологий (W3Techs, BuiltWith, WebTechSurvey), поиск по документации и открытым
репозиториям. Прямые заголовки ответов из песочницы недоступны, поэтому часть
выводов — по косвенным признакам, и я это помечаю.

**Важная оговорка.** Снаружи видно веб-сервер, CDN, фреймворк и сертификат.
**Базу данных снаружи увидеть нельзя** — можно только предположить по стеку и
косвенным признакам. Ниже честно разделено: «подтверждено» и «предположение».

## RollerCoin (rollercoin.com)

| Слой | Что видно | Статус |
|---|---|---|
| CDN и защита | Cloudflare (сервер, прокси, DNS) | подтверждено |
| Фронтенд | Next.js + React, Bootstrap 4, X-Powered-By: Next.js | подтверждено |
| Бэкенд | Node.js, Express | подтверждено (отпечаток Express на сайте) |
| Хостинг приложения | США; на поддомене — Vercel; в почте — Amazon SES | подтверждено частично |
| Сайт-визитка | WordPress + Yoast, отдельный GitBook для документации | подтверждено |
| Маркетинг | SendPulse, Zendesk, Trustpilot, Google Workspace, Discord | подтверждено |
| База данных | не определяется снаружи. При Next.js + Express это почти всегда PostgreSQL или MongoDB на AWS/RDS | **предположение** |

Что это значит: это классическое «серверное» приложение за Cloudflare. У них есть
публичный JSON API (`api.rollercoin.com`), которым пользуются сторонние
дашборды — то есть игра построена как API-first, как и у нас. При их масштабе
(миллионы регистраций) Cloudflare Workers и Durable Objects были бы не по карману:
оплата за длительность объектов и записи строк съедает выгоду, поэтому крупные
игры держат свои Node-серверы.

## CryptoCrops / CXL Games (cryptocrops.net, cxlgames.com, lightningquest.net)

| Слой | Что видно | Статус |
|---|---|---|
| CDN и защита | Cloudflare (сервер, прокси, DNS), HTTP/3, Zstd | подтверждено |
| Сертификат | GlobalSign — то есть не бесплатный Universal SSL, а выданный отдельно | подтверждено |
| Фронтенд | собственный SPA на JavaScript (Vite-подобная сборка: `/assets/…?v=2`), без Next.js/Nuxt | подтверждено частично |
| Почта | Cloudflare Email Routing (MX на Cloudflare) | подтверждено |
| Аналитика | Google Tag Manager, Cloudflare Insights, Ahrefs | подтверждено |
| Выплаты | FaucetPay API + собственный CXL Wallet | подтверждено по описанию проекта |
| База данных | снаружи не видна. Архитектура «статический SPA + внешние сервисы» допускает и Supabase/Postgres, и собственный VPS с SQL | **предположение** |
| Каталог | bestcryptoearningsites.com — отдельный SEO-проект на том же стеке | подтверждено |

Что это значит: у них **не** Cloudflare Workers — это статика за Cloudflare плюс
какой-то бэкенд, к которому SPA ходит по API. Их сила не в инфраструктуре, а в
том, что вся монетизация вынесена во внешние сервисы (FaucetPay, офферволы,
собственная PTC-сеть ADS by UAP), поэтому серверу не нужно ничего сложного.

## Nocid (nocid.fun)

| Слой | Что видно | Статус |
|---|---|---|
| CDN и защита | Cloudflare (сервер, прокси, DNS), HTTP/3, Zstd, IPv6 | подтверждено |
| Сертификат | GlobalSign, тот же CA, что у CXL | подтверждено |
| Фронтенд | JavaScript-приложение, фреймворк по отпечатку не определяется (своя сборка или минификация без маркеров) | подтверждено частично |
| Почта | данных нет | — |
| База данных | снаружи не видна | неизвестно |
| Модель | «майнинг-комната»: 10 000+ игроков, выплаты каждые 10 минут в 8 монетах, лиги, лутбоксы | подтверждено по описанию сайта |

Что это значит: тот же шаблон, что у CXL — приложение за Cloudflare, без
признаков serverless-платформы. Выплаты каждые 10 минут в восьми монетах требуют
своего кошелька и бухгалтерии, а не только FaucetPay, — это заметно более
тяжёлая операционка, чем выглядит.

Все четыре проекта стоят за Cloudflare — это стандарт отрасли, и наш выбор
платформы не является ошибкой. Разница в другом: они вынесли сложность в
монетизацию и внешние сервисы, а мы вложили её в серверную честность
(журнал, идемпотентность, изоляция миров).

## Чему это учит

1. **Классические серверы нужны только на масштабе.** RollerCoin ушёл на
   Node-серверы, когда игроков стали миллионы. До тысяч игроков в день Workers
   дешевле и проще.
2. **Секрет CXL и Nocid — не инфраструктура.** Оба живут на статике за
   Cloudflare и платят через FaucetPay или свой кошелёк. Их «сервер» — это
   рекламная сеть и офферволы, а не железо.
3. **Публичный API — это дистрибуция.** Вокруг RollerCoin пишут сторонние
   дашборды, потому что API открыт. Нам это не нужно на старте, но публичная
   статистика мира (рейтинг сезона) — дешёвый способ дать людям повод
   возвращаться и делиться.
4. **Наша архитектура — не слабое место.** Ни у одного из трёх нет ни журнала с
   хеш-цепочкой, ни идемпотентности, ни изоляции миров. Это не мешает им
   зарабатывать, но и нам не мешает: на скорость запуска влияет экономика, а не
   Durable Objects.
