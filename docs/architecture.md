# Crypto Astra — архитектура v1

## Текущая реализация

- **Frontend:** статический мобильный сайт на Cloudflare Pages.
- **Auth:** Supabase Auth — регистрация и вход по email/паролю.
- **Database:** Supabase PostgreSQL — профиль, кошелёк, ракеты, склад, экспедиции, журнал операций и фонд наград.
- **Game actions:** защищённые PostgreSQL RPC-функции `purchase_rocket`, `launch_expedition`, `complete_expedition`.
- **RLS:** игрок читает только собственные данные; клиент не может напрямую изменять баланс, ракеты, инвентарь, экспедиции или журнал.

## Границы доверия

### Браузер
Отвечает за интерфейс и отображение данных. Клиентские значения можно подделать, поэтому браузеру нельзя доверять при расчёте баланса, стоимости покупки, длительности экспедиции или наград.

### PostgreSQL
Критичные операции выполняются атомарными RPC-функциями:
- проверяется `auth.uid()`;
- кошелёк блокируется на время списания;
- стоимость и длительность берутся из серверного каталога;
- время экспедиции рассчитывается по серверному времени;
- награда определяется сервером;
- операции записываются в `wallet_ledger` с idempotency key;
- повторное завершение экспедиции не начисляет награду второй раз.

### Cloudflare
- Pages размещает frontend и автоматически публикует коммиты из GitHub.
- Turnstile и дополнительный Worker/API для антибот-проверок — следующий этап.
- Секреты нельзя помещать в публичные JS-файлы или Git.

## Безопасность

1. RLS включён на всех таблицах в `public`.
2. Игроку разрешено читать только собственные строки; каталоги доступны для чтения.
3. Прямые INSERT/UPDATE/DELETE для игровых таблиц из браузера запрещены.
4. RPC-функции проверяют `auth.uid()`, а выполнение отозвано у `PUBLIC` и `anon`, выдано только `authenticated`.
5. Секретные ключи Supabase и Turnstile secret нельзя публиковать.
6. Для новых операций использовать уникальный idempotency key.
7. Использовать серверное время UTC.
8. Реальные выплаты требуют отдельного финансового журнала, контроля доступного фонда и проверки провайдера.

## Создание игрока

После регистрации триггер в закрытой схеме `private` автоматически создаёт:
- профиль;
- кошелёк с 500 тестовыми ASTRA Coins, 3 единицами топлива и 0 XP;
- ракету Scout;
- шесть пустых ячеек инвентаря.

## Демо-ограничение

ASTRA Coins и игровые предметы сейчас являются только внутриигровыми значениями. Astra Pool не начисляет деньги. Реклама и выплаты не подключены.
