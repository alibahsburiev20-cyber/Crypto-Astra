# Мини-игра «Астероидный залп» (этап 13)

Короткий забег на 45 секунд: корабль внизу, сверху падают астероиды, между ними
кристаллы. Собрал кристалл — плюс очки, врезался — минус. Цель — победа: 150 очков
за забег.

## Почему счёт нельзя накрутить

Обычная ошибка таких игр — «клиент присылает счёт». Здесь наоборот:

1. Сервер выдаёт **зерно** (`seed`) и записывает забег в `minigame_runs`.
2. Клиент строит поле из зерна **тем же кодом**, что и сервер
   (`worker/src/shared/minigame.ts` → `client/minigame-sim.js`).
3. В конце клиент отправляет **трассу**: пары «время → x корабля», примерно
   25 отсчётов в секунду.
4. Сервер проверяет трассу (время по возрастанию, координаты в поле, скорость не
   больше 900 px/с) и сам считает попадания и сборы.

Подделать можно только идеальную трассу — но она обязана уважать предел скорости,
то есть это и есть игра. Мусорная трасса («телепорт», обрыв, слишком короткая)
отбивается и **сжигает попытку**, иначе можно было бы бесплатно перебирать варианты.

Файл `client/minigame-sim.js` генерируется (`npm run build:minigame`), тест
`arenaUi.test.ts` сверяет его со свежей сборкой: расхождение валит сборку.

## Правила и числа

| Параметр | Значение |
| --- | --- |
| Длительность забега | 45 с |
| Попытки в сутки | 5, Premium **+2** |
| Кристалл | +10 очков |
| Пробоина | −15 очков |
| Победа | 150 очков |
| Награда за забег | 1–45 ASTRA + очки (до 400) |
| Суточный потолок | 150 ASTRA, 400 очков |
| Медали | 25 / 50 / 100 побед: 300 / 600 / 1200 ASTRA |

Потолок нужен, чтобы забеги не заменили игру: за час их не нафармить больше, чем
даёт один рейс.

## Маршруты

| Метод | Путь | Что делает |
| --- | --- | --- |
| GET | `/minigame` | попытки, победы, ступени, сегодняшние награды, последние забеги |
| POST | `/minigame/start` | выдаёт `runId` и `seed`, тратит попытку (нужен `Idempotency-Key`) |
| POST | `/minigame/finish` | принимает `{ runId, trace }`, считает результат, платит, выдаёт медали |

`/me` отдаёт короткую сводку `minigame { attempts, wins, best, nextTier }` и флаг
`premium` — из него клиент рисует шкалы без лишнего запроса.

## Что важно не сломать

- **Premium не влияет на деньги.** Он даёт только +2 попытки в сутки.
- **Медали не входят в суточный потолок** — это разовое достижение, а не фарм.
- **Просроченный забег не платит.** `ends_at` = старт + 45 с + 90 с на отправку.
- **Одинаковый `Idempotency-Key`** возвращает тот же ответ и не платит дважды.
- **Трасса идёт в журнал только суммами**: `reason=minigame` и `minigame_award`,
  поэтому сверка мира (`verifyLedger`) сходится.

## Локальная проверка

```bash
npm run build:minigame     # пересобрать client/minigame-sim.js
npx vitest run minigame arenaUi
```
