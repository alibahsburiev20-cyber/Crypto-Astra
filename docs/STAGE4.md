# Этап 4 «Социальное»

Гильдии, миссии, рефералы, достижения и Astra Pass. Всё считается на сервере, все
награды проходят через Ledger. Денег, платного Pass, чата и выплат в этом этапе
**нет** — это зафиксировано в `docs/ROADMAP.md` и в тестах.

## Что сделано

| Фича | Правила | Код |
|---|---|---|
| Гильдии | создание 500 ASTRA (сток), до 10 человек, вход по коду, роли лидер/офицер, рейтинг — сумма очков сезона участников | `worker/src/world/modules/guilds.ts` |
| Миссии | 3 дневные + 1 недельная, прогресс только по фактам (`ledger`, `expeditions`, `craft_jobs`, `market_sales`) | `modules/missions.ts` |
| Рефералы | код 7 символов, награда 150 ASTRA обоим после 5 рейсов приглашённого, не больше 20, самоприглашение запрещено | `modules/referrals.ts` |
| Достижения | 10 бейджей, награда только косметика (знак и титул), ASTRA и очки не начисляются | `modules/achievements.ts` |
| Astra Pass | бесплатный трек из 10 уровней по очкам сезона; награды: ASTRA, второй слот крафта на 3-м уровне, бейджи, титул. Награды привязаны к сезону, слот и косметика — навсегда | `modules/pass.ts` |

Миграция мира — `worker/schema/world/010_social.sql`, справочная копия в
`worker/src/world/schema.ts`. Новых таблиц D1 этап не требует.

## Таблицы мира

`guilds`, `guild_members`, `missions` (отметки о выданной награде),
`referrals`, `achievements`, `pass_claims` (с `season_id`: в новом сезоне очки
обнуляются, а награды уровней можно забрать снова). Мир, созданный до появления
`season_id`, пересобирает таблицу на старте (`migratePassClaimsSeason`) и
сохраняет старые отметки как награды прошлого сезона. Прогресса миссий в таблицах нет
намеренно: его нельзя накрутить, потому что он пересчитывается по фактам.

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/social` | миссии дня и недели, достижения, Pass, очки |
| POST | `/missions/claim` | `{ missionId }` — забрать награду готовой миссии |
| POST | `/pass/claim` | `{ level }` — забрать награду уровня Pass |
| GET | `/guild` | своя гильдия, участники, топ, код приглашения |
| POST | `/guild/create` | `{ name, tag }` — создать за 500 ASTRA |
| POST | `/guild/join` | `{ code }` — войти по коду |
| POST | `/guild/leave` | выйти (лидер передаёт роль или распускает гильдию) |
| POST | `/guild/kick` | `{ playerId }` — исключить (офицер и лидер) |
| POST | `/guild/role` | `{ playerId, role }` — выдать роль |
| POST | `/guild/rename` | `{ name, tag }` — переименовать (лидер) |
| POST | `/referrals/apply` | `{ code }` — применить код приглашения |

Ошибки этапа: `bad_mission`, `mission_incomplete`, `mission_claimed`,
`bad_pass_level`, `pass_locked`, `pass_claimed`, `craft_queue_full`,
`bad_guild_name`, `bad_guild_tag`, `guild_not_found`, `guild_full`,
`guild_already_member`, `not_in_guild`, `bad_role`, `not_allowed`,
`self_referral`, `referral_already_applied`, `referral_limit`,
`referral_not_found`. Все они переведены в клиенте (`client/app.js`) — за этим
следит `worker/test/unit/client-errors.test.ts`.

## Числа и экономика

Все награды ограничены так, чтобы игра оставалась в коридоре поглощения
70–90 %. После среза цифры такие:

| Источник | Награда | Доля выпуска (30 дн., 200 игроков) |
|---|---|---|
| дневная миссия | 10 ASTRA + 25 очков | 5.4 % |
| дневная сложная миссия | 20 ASTRA + 40 очков | входит в 5.4 % |
| недельная миссия | 50 ASTRA + 150 очков | 1.4 % |
| Astra Pass, 10 уровней | 150 ASTRA суммарно + косметика | 1.2 % |
| реферал | 150 ASTRA каждому | 0.8 % |
| создание гильдии | −500 ASTRA (сток) | — |

`npm run simulate -- --social` даёт **72.4 %** поглощения, `--mix --social` —
**73.1 %** при базовых 78.8 %. Награды за сезон считать отдельно:
`npm run simulate -- --season --social`.

Пороги Pass — `400, 900, 1500, 2200, 3000, 3900, 4900, 6000, 7800, 10000`
очков. При прогоне на 30 дней средний уровень 7: новичок доходит до 3–4,
активный игрок — до 9–10 к концу 56-дневного сезона. Второй слот крафта
(`PASS_SLOT_LEVEL = 3`) открывается уже на 1500 очках, чтобы новые игроки
чувствовали прогресс за первую неделю.

## Клиент

Два новых раздела в меню и доке:

- **«Задания»** — три дневные карточки с прогресс-барами, недельная миссия,
  трек Astra Pass с кнопками «Забрать», сетка достижений;
- **«Команда»** — своя гильдия или форма создания/входа, участники с ролями
  и действиями, рейтинг гильдий, карточка реферала с кодом и полем ввода.

Спрайты: `client/icons/nav/missions.png`, `icons/nav/guild.png` (64 px),
`icons/social/pass.png` (128 px), `icons/social/badge.png` (64 px),
`icons/social/banner.png` (96 px). Палитра и
правила — `docs/ART.md`.
