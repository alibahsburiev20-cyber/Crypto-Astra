# Глоссарий

- **ASTRA** — внутриигровая валюта. Не деньги, не токен, не актив; вывода нет.
- **Claim** — периодическая награда: +5 ASTRA, не чаще раза в 15 минут, до 96 в сутки.
- **Ledger** — неизменяемый журнал операций мира с хеш-цепочкой.
- **Мир (World)** — один Durable Object SQLite на ≤ 100 игроков.
- **WorldLobby** — объект, который единолично выдаёт места в мирах.
- **DO** — Durable Object, объект Cloudflare с собственным SQLite и alarm.
- **D1** — глобальная SQL-база Cloudflare для аккаунтов и сессий.
- **RPC** — вызов метода Durable Object из Worker.
- **Идемпотентность** — повтор с тем же ключом не меняет состояние, а возвращает
  сохранённый ответ.
- **Alarm** — единственный таймер Durable Object; будит планировщик.
- **jobs** — таблица отложенных задач мира.
- **seed** — случайная строка рейса; из неё детерминированно считаются награда,
  износ и события, поэтому результат нельзя переиграть.
- **alloy_plate** — компонент для крупного ремонта; появится в крафте на этапе 2.
- **Гейт** — проверка результата этапа, без неё следующий этап не начинается.
- **Astra Pool** — общий пул доли выручки; на этапе 1 не считается.
