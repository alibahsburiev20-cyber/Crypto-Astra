# Static art assets

Анимации запрещены для Crypto Astra v1. Использовать только статичные файлы.

Плановый комплект: 93 файла:
- 4 логотипа и брендовых элемента;
- 8 фоновых изображений;
- 5 ракет;
- 6 планет;
- 6 ресурсов;
- 8 деталей ракет;
- 8 космических объектов;
- 8 аватаров;
- 40 SVG-иконок интерфейса.

Рекомендуемые форматы:
- WebP для фонов;
- PNG/WebP с прозрачностью для объектов;
- SVG для интерфейсных иконок.

Имена файлов — латиницей, lowercase, kebab-case. Не добавлять GIF, APNG, анимированные WebP или sprite sheets.
