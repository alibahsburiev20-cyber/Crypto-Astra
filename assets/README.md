# Static art assets

Анимации запрещены для Crypto Astra v1. Используются только статичные SVG и CSS-элементы. Никаких GIF, APNG, анимированных WebP, sprite sheets, CSS keyframes или transition-анимаций.

## Уже добавлено

- `branding/logo-mark.svg` — знак бренда и favicon.
- `backgrounds/spaceport-hero.svg` — статичный фон стартового экрана.
- `ships/scout.svg`, `miner.svg`, `explorer.svg`, `titan.svg`, `galaxy.svg` — пять ракет.
- `planets/ferra.svg`, `cuprum.svg`, `azur.svg`, `ameth.svg`, `quantis.svg`, `stellara.svg` — шесть планет.
- `resources/iron-ore.svg`, `copper.svg`, `blue-crystal.svg`, `amethyst.svg`, `quantum-stone.svg`, `stellar-core.svg` — шесть ресурсов.

Всего сейчас: **19 статичных SVG-файлов**.

## Следующие группы графики

- 8 деталей ракет: двигатель, топливный бак, корпус, навигация, грузовой отсек, солнечная панель, щит, буровой модуль.
- 8 космических объектов: станция, астероиды, спутник, контейнер, маяк, дрон, обломки.
- 8 аватаров пилотов.
- 40 SVG-иконок интерфейса.
- Дополнительные фоновые изображения для ангара, карты галактики, планет и мастерской.

Форматы: SVG для иллюстраций и иконок; WebP/PNG для крупных растровых фонов и текстур. Имена — lowercase, kebab-case.
