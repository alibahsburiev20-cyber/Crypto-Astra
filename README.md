# Crypto Astra

Мобильная браузерная космическая экономическая игра.

> Текущий этап: рабочий браузерный прототип. Supabase Auth и серверные игровые операции подключены; ASTRA Coins остаются тестовой внутриигровой валютой. Реклама, Turnstile и реальные выплаты пока не подключены.

## Что реализовано

- Адаптивный интерфейс: настольная боковая навигация и компактная мобильная панель.
- Единая визуальная система: строгая типографика, сдержанная палитра, тонкие границы и единые состояния элементов.
- Разделы: космопорт, ангар, экспедиции, склад, верфь, Astra Pool и профиль.
- Пять классов кораблей и шесть типов ресурсов с базовыми SVG-иллюстрациями и дополнительными WebP-ассетами из `assets/game-art/`.
- Авторизация Supabase и загрузка игрового профиля; покупка кораблей и операции экспедиций выполняются через серверные RPC.
- Экономические ограничения и тестовый статус явно обозначены в интерфейсе.
- Только статичная графика. Анимации и CSS-переходы не используются.

## Локальный запуск

Открой `index.html` в браузере. Сборщик и зависимости пока не требуются.

## План архитектуры

- **Frontend:** статический сайт, оптимизированный для мобильных устройств.
- **Backend:** Supabase PostgreSQL RPC для защищённых игровых операций. Cloudflare Worker и Turnstile — следующий этап антибот-защиты и дополнительных серверных проверок.
- **Database:** Supabase PostgreSQL. Игроки, инвентарь, ракеты, экспедиции, журнал операций и фонд наград.
- **Anti-bot:** Cloudflare Turnstile с обязательной серверной проверкой токена.
- **Hosting:** Cloudflare Pages через GitHub.

## Безопасность и экономика

- Браузер не является источником истины для валюты, таймеров и результатов экспедиций.
- Секретные ключи Supabase и Turnstile secret хранятся только на сервере.
- Начисления и списания должны быть атомарными и записываться в неизменяемый журнал.
- ASTRA Coins — внутриигровая валюта, не равная реальным деньгам.
- Astra Pool распределяет только фактически полученную и подтверждённую чистую выручку. Никаких гарантированных доходов.
- Выплаты подключаются только после проверки условий платёжного провайдера и применимых юридических требований.

## Текущее подключение

- Supabase project: `crypto-astra` (Frankfurt / `eu-central-1`).
- Публичный Supabase URL и publishable key находятся в `supabase/config.js`. Publishable key предназначен для браузера; секретные ключи туда добавлять нельзя.
- Регистрация и вход реализованы через Supabase Auth.
- При регистрации серверный триггер создаёт профиль, кошелёк с тестовым стартовым балансом, ракету Scout и пустые ячейки склада.
- Покупка ракеты, запуск и завершение экспедиции выполняются через защищённые PostgreSQL RPC-функции. Клиент не может напрямую менять кошелёк и склад.
- SQL миграции находятся в `supabase/migrations/`.

### Важное перед публичным запуском

1. Настроить SMTP в Supabase Auth, чтобы письма подтверждения регистрации доставлялись игрокам.
2. Настроить Cloudflare Turnstile и серверную проверку токенов.
3. Добавить rate limiting, мониторинг злоупотреблений и административный интерфейс.
4. Настроить домен и юридические документы.
5. Реальные награды и выплаты не включать до отдельного финансового аудита и проверки требований платёжного провайдера.

**В интерфейсе нет анимаций:** только статичные изображения, иконки и неподвижные элементы.


## Визуальная система

Интерфейс оформлен как рабочая панель космической экспедиционной компании, а не как набор промо-карточек: постоянная навигация, понятная иерархия данных, нейтральные поверхности, функциональные статусы и компактные метрики. На мобильных устройствах навигация перестраивается в нижнюю панель.

В базовом наборе `assets/` остаются 19 статичных SVG-иллюстраций интерфейса и стартовой системы. Дополнительный каталог `assets/game-art/` содержит 68 WebP-изображений: 9 кораблей, 8 пилотов, 16 планет (8 pixel и 8 realistic), 14 ресурсов, 8 модулей и 13 объектов. WebP уже подключены в ангаре, складе, карточках модулей, блоке космопорта и профиле. Альтернативные изображения планет сохранены в отдельных каталогах до выбора единого визуального стиля. Исходный лист и ZIP-архив лежат в `source-sheets/` и `source-archives/`.

**Требование v1:** интерфейс полностью статичный. CSS-анимации, переходы, GIF и анимированные изображения не используются.
