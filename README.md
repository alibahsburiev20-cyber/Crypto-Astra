# Crypto Astra

Мобильная браузерная космическая экономическая игра.

> Текущий этап: интерфейсный прототип. Все игровые балансы и действия демонстрационные. Реальные аккаунты, серверная экономика, реклама и выплаты пока не подключены.

## Что есть в прототипе

- Адаптивный интерфейс для телефонов и компьютеров.
- Космопорт, ангар, экспедиции, склад, рынок, Astra Pool и профиль.
- Пять типов ракет: Scout, Miner, Explorer, Titan, Galaxy.
- Шесть типов космических ресурсов.
- Демо-покупка ракет, запуск экспедиций и получение тестовых ASTRA Coins.
- Только статичная графика и неподвижные элементы: анимации не используются.

## Локальный запуск

Открой `index.html` в браузере. Сборщик и зависимости пока не требуются.

## План архитектуры

- **Frontend:** статический сайт, оптимизированный для мобильных устройств.
- **Backend:** Cloudflare Worker. Проверка авторизации, CAPTCHA, таймеров и всех игровых операций.
- **Database:** Supabase PostgreSQL. Игроки, инвентарь, ракеты, экспедиции, журнал операций и фонд наград.
- **Anti-bot:** Cloudflare Turnstile с обязательной серверной проверкой токена.
- **Hosting:** Cloudflare Pages через GitHub.

## Безопасность и экономика

- Браузер не является источником истины для валюты, таймеров и результатов экспедиций.
- Секретные ключи Supabase и Turnstile secret хранятся только на сервере.
- Начисления и списания должны быть атомарными и записываться в неизменяемый журнал.
- ASTRA Coins — внутриигровая валюта, не равная реальным деньгам.
- Astra Pool распределяет только фактически полученную и подтверждённую чистую выручку. Никаких гарантированных доходов.
- Выплаты подключаются только после проверки условий платёжного провайдера и применимых юридических требований.
